# Axion Defect Monitoring

This repository contains a lightweight defect monitoring dashboard for tracking operational defects across teams.

## Features

- KPI summary cards for total, open, critical, SLA-breached, and closed defects
- Filterable defect list by status, severity, and search term
- Lightweight JSON API for dashboard data
- Static, browser-based dashboard UI

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000 in your browser.

## Test

```bash
npm test
```
