# Source documents and guides

This folder retains the business source material, learning guides, proposals,
infographics and document-generation scripts. It is distinct from `docs/`, which
contains the current project business and architecture documentation.

Start with [the current repository map](../docs/repository-structure.md) when
deciding where implementation files belong.

- `Business Requirements Document.docx`: business discovery source.
- `AI_NATIVE_ENGINEERING_INITIAL_DISCUSSION.md`: proposed enterprise architecture
  and folder tree, with unresolved decisions; not the implemented folder mandate.
- `AI_NATIVE_TASK_1_PROJECT_FOUNDATION.md`: earlier foundation proposal; some
  suggested artifacts are deferred in the current landing-page implementation.
- `BOARD_DEFECT_INSPECTION_TASK_5_BEGINNER_GUIDE_ENTERPRISE_STANDARD.md`: adapted
  Task 5 guide, retaining `apps/ui/` and the existing validator preparation path.
- `Customer_Onboarding_*`: reference tutorials, not board-project contracts.

The active schema remains `../specs/schemas/ui-spec.schema.json`. Neither a guide
nor a folder cleanup moves it into a new `contracts/` or top-level `schemas/` tree.
Implementation evidence lives in `../specs/TASK-*-IMPLEMENTATION-REPORT.md`.
